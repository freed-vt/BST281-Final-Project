# BST281-Final-Project
This repository is for all notebooks and output files from BST 281 Spring 2026 final project.

This project is an exploration of the single-cell RNA-sequencing dataset generated by Bellissimo *et al.* (2020) [https://pmc.ncbi.nlm.nih.gov/articles/PMC7094023/] and stored in GEO [https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE144482]. 

Analysis Module 1 focuses on re-annotation and clustering of the cell populations within the dataset, as well as differential expression analysis, using the count_matrix available in GEO.
