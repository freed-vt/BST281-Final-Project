# BST281-Final-Project
This repository is for all notebooks and output files from BST 281 Spring 2026 final project.

This project is an exploration of the single-cell RNA-sequencing dataset generated by Bellissimo *et al.* (2020) [https://pmc.ncbi.nlm.nih.gov/articles/PMC7094023/] and stored in GEO [https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE144482]. 

Analysis Module 1 focuses on re-annotation and clustering of the cell populations within the dataset, as well as differential expression analysis, using the count_matrix available in GEO. I did a fair bit of QC with the dataset as well. I then performed differential expression analysis between WT and Runx1 KO LSKs using the Seurat object and clusters obtained from Module 1. This object is committed here as GSE144482_Runx1_LSK_reclustered_FR.rds. The relevant metadata columns for anything downstream besides read columns are genotype and manual_celltype which represent the re-annotations that I performed. 

Note that while running edgeR for Module 2 I (FR) realized that there is only one biological replicate per sample, which makes DEG assessment somewhat confounded. For now, I have run edgeR with a manual dispersion threshold using a biological coefficient of variation of 0.25. This may not be super valid so stay tuned. If we stick with this method then I will export the edgeR results as .csv files for further analysis.
